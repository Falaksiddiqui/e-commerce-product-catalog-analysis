# E-commerce Product Catalog Data Analysis

## Overview

This project demonstrates basic e-commerce product catalog data management and analysis using Microsoft Excel.

The dataset contains product information such as Product ID, Product Name, Category, Price, Stock, Brand, and Status.

## Objectives

- Organize product catalog information
- Identify and correct missing or inconsistent data
- Review pricing and product information for accuracy
- Verify product information using VLOOKUP
- Summarize catalog data using Pivot Tables
- Improve data consistency and organization

## Excel Skills Used

- VLOOKUP
- Pivot Tables
- Data Cleaning
- Data Validation
- Filtering
- Sorting
- IF
- SUM
- AVERAGE
- COUNT
- COUNTIF

## Key Activities

1. Created and organized a product catalog dataset.
2. Reviewed records for missing and inconsistent information.
3. Corrected inaccurate product data and pricing.
4. Used VLOOKUP to retrieve product information from a reference table.
5. Created Pivot Tables to analyze product counts and average prices by category.
6. Used filtering, formulas, and data validation to improve data accuracy.
